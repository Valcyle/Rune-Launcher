# Rune Launcher 1.0.0-beta.10

Pre-release. Public builds are launcher-only and do not bundle the Rune mod
loader.

## Highlights

- Public builds no longer embed or extract `RuneCore.dll`.
- The launcher now focuses on profile management, mod import, dependency checks,
  and external DLL injection.
- Added a private `-WithLoader` build mode for loader testing. Do not publish
  that build while loader distribution is paused.
- Added MIT licensing, third-party notices, and logo/artwork attribution.

## Changes since 1.0.0-beta.9

- Changed the default build to launcher-only; `RuneCore.dll` is optional and only
  embedded with `build.ps1 -WithLoader`.
- Reduced the public executable from roughly 3.3 MB to 2.8 MB.
- Fixed `build.ps1` path resolution when generating embedded resources.
- Regenerated embedded UI resources.
- Fixed the application icon.
- Added `LICENSE`, `NOTICE`, `AUTHORS.md`, `TRADEMARKS.md`,
  `THIRD_PARTY_NOTICES.md`, and `LICENSE-ARTWORK`.
- Added a license card and updated credits in the About screen.
- Added SPDX headers to first-party source files.
- Updated README and added `docs/architecture.md`.
- Added ignore rules for runtime session files, debug flags, WebView2 data, and
  sensitive local files.

## Behavior

- Public build: injects `external/*.dll` and mod entrypoint DLLs directly.
- The Rune mod API lifecycle (`RuneMod_Initialize`) is not available in the
  public build.
- No `session.json` is written by the public build.
- Profile management, mod import, and dependency resolution are unchanged.

## Known limitations

- RuneCore / RuneModLoader is not included. The loader remains a private beta.
- No native game-function hooks, game events, config/services API, or multiplayer
  support in this release.
- The auto-update flow still downloads the release executable without a separate
  signature check. Verify the published SHA256 checksum.
- Mod DLLs are arbitrary native code and are not sandboxed.

## Installation

1. Download the release zip.
2. Extract it to a writable folder.
3. Run `launcher.exe`.
4. The launcher may offer to install itself to `%LOCALAPPDATA%\Rune`.

WebView2 Runtime is required. It is preinstalled on Windows 11 and most updated
Windows 10 systems.

## Auto-update

This release publishes a standalone `launcher.exe` asset for the built-in
updater, in addition to the zip for manual installs. The updater looks for a
release asset whose name ends with `.exe`; publishing only the zip would disable
automatic updates.

The default `stable` update channel queries GitHub's `/releases/latest`, which
ignores pre-releases. Users on the `beta` channel will see this release; stable
users will not unless it is published as a normal release.

## Verification

SHA256 checksums are published alongside the release assets.
