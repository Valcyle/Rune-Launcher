# Rune Launcher 1.0.0-rc.1

Pre-release updater hotfix for the beta channel.

## Updater fix

- Fixed SemVer prerelease comparison. Previously `beta.10` sorted below
  `beta.9` and `beta.7` because prerelease strings were compared lexically.
- The beta channel now selects the highest SemVer release instead of assuming
  the first GitHub API entry is newest.
- Existing `beta.7`–`beta.10` builds compare `rc.1` as newer than `beta.*`, so
  they can auto-update to this build when the beta channel is selected.

`stable` still uses GitHub's `/releases/latest` and therefore ignores
pre-releases. Users on stable need to switch to the beta channel or install
manually once.

## Unchanged

- Public builds remain launcher-only; RuneCore is not bundled.
- Profile management, mod import, dependency checks, and external DLL injection
  are unchanged.
- The release includes a standalone `launcher.exe` asset for the built-in
  updater, plus a zip for manual installs and license notices.

## Verification

- `npm run lint` passes with existing warnings only.
- `npm run build` succeeds.
- Launcher-only build succeeds; `EMBEDDED_RUNE_CORE_DLL_SIZE` is `0`.
- Version comparison cases verified: `beta.9 < beta.10`, `beta.10 > beta.9`,
  `1.0.0 > 1.0.0-rc.1`, `rc.1 > beta.10`.
